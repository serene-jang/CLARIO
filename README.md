## 1. CLARIO 소개

CLARIO는 여러 사람이 함께 사용하는 **디지털 공간을 효율적으로 관리하는 웹 플랫폼**입니다.
참여자의 화면 확인, 자료 전달, 활동 관리 등을 **한곳에서** 할 수 있습니다.

- **설치 없이 시작해요.** 관리자와 참여자 모두 웹 브라우저로 접속하면 돼요.
- **관리자는 구글 계정으로 로그인해요.** 비밀번호를 따로 만들 필요가 없어요.
- **참여자는 계정이 필요 없어요.** 초대 코드와 이름만 입력해요.
- **저장은 관리자 본인의 공간에 해요.** 녹화와 제출물은 관리자의 구글 드라이브 또는 PC 폴더에 저장하고, 서버에는 남기지 않아요.

## 2. 이런 상황에 쓰면 좋아요

| 상황 | CLARIO로 이렇게 해요 |
|---|---|
| 수업 중 학생이 지금 무엇을 하는지 궁금할 때 | 여러 학생의 화면을 한 화면에 모아 보고, 눌러서 크게 확인해요. |
| 자료나 링크를 한 번에 나눠주고 싶을 때 | 공지, 링크, 파일을 전체 또는 일부에게 보내요. |
| 수행평가나 시험을 진행할 때 | 문서·파이썬·스크래치로 작성하게 하고, 제출과 작성 과정을 확인해요. |
| 활동에 필요한 사이트만 열고 싶을 때 | 허용한 사이트만 열리도록 설정해요(도우미 설치 필요). |
| 활동 장면을 기록해 두고 싶을 때 | 화면을 녹화해 내 드라이브나 PC에 저장해요. |

## 3. 시작하기

1. **CLARIO 웹사이트에 접속해 관리자 계정으로 로그인합니다.**
   - 관리자용 주소: https://app-clario-v3-42e4.azurewebsites.net/teacher.html
   - `Google 계정으로 로그인` 버튼을 누르고 본인의 구글 계정을 선택해요.
2. **새로운 관리 공간을 만듭니다.**
   - 공간 이름을 입력하고 `수업 코드 만들기`를 눌러요.
   - 6자리 초대 코드가 만들어져요.
3. **참여자에게 접속 주소 또는 초대 코드를 전달합니다.**
   - `학생 링크 복사` 버튼으로 주소를 복사해서 메신저나 화면으로 알려주세요.
4. **참여자가 접속하면 관리자 화면에서 확인합니다.**
   - 참여자가 들어오면 화면 카드가 나타나고, 접속 상태가 표시돼요.

> 💡 처음 한 번 **저장 위치**를 정해 두면 좋아요. `💾 저장 위치`에서 구글 드라이브를 연결하거나 PC 폴더를 골라요.

## 4. 참여자는 이렇게 들어와요

1. 참여자용 주소(https://app-clario-v3-42e4.azurewebsites.net/student.html)에 접속해요.
2. **초대 코드 6자리**와 **이름**(예: `10203 홍길동`)을 입력하고 `참여하기`를 눌러요.
3. 화면 확인이 필요한 활동이면 `화면 공유 시작`을 누르고, 공유 창에서 **전체 화면**을 선택해요.
4. 공유 중에는 화면에 표시가 계속 보여요. 공유는 **참여자가 직접 허용**한 경우에만 이뤄져요.

## 6. 기능별 사용 방법

### 🖥 화면 모니터링
- 참여자가 화면 공유를 시작하면 관리자 화면에 **참여자별 카드**가 나타나고, 화면이 약 1.5초마다 갱신돼요.
- 카드를 누르면 **크게 보기**로 바뀌고, 더 선명한 화면이 짧은 간격으로 갱신돼요.
- 크게 보기에서 `📝 작업 보기`, `⏯ 작성 과정`, `📋 알림·방문 기록`으로 이동할 수 있어요.

### 👥 참여자 관리
- 참여자 카드에 **접속 상태**(공유 중 / 공유 안 함 / 연결 끊김)가 표시돼요.
- 상단에 `접속 N / 전체 M`으로 현재 접속 인원을 확인해요.
- 진행 중인 공간은 `내 수업 목록`에서 다시 열 수 있어요.

### 🔗 자료 전달
- `🔗 과제 링크`로 주소를 보내면 참여자 화면에서 바로 열 수 있어요.
- `📁 파일 보내기`로 **여러 파일을 한 번에** 보낼 수 있어요. 그림, PDF, 동영상, 소리, 문서, 압축 파일, 노트북 파일, 스크래치 작품 등 종류는 상관없어요.
- 참여자는 받은 파일을 **앱 안에서 바로 열어** 볼 수 있어요.

| 받은 파일 | 참여자 화면에서 |
|---|---|
| 그림 · PDF · 동영상 · 소리 | 바로 보기·재생 |
| 글·코드(txt, py, csv, md, json 등) | 내용 보기 |
| 노트북(.ipynb) | 셀과 실행 결과를 노트북 모양으로 보기 |
| 문서(.docx) | 앱 안에서 바로 고쳐 쓰고 제출 |
| 압축(.zip) | 안의 파일 목록을 보고 눌러서 열기(한글 파일명 지원) |
| 스크래치(.sb3) | 편집기로 열어 작업하고 제출 |
| 한글·파워포인트·엑셀 | 내려받아 컴퓨터 프로그램으로 열기 |

- 참여자는 **📂 파일 고르기**로 컴퓨터의 파일을 골라 제출해요. 여러 개를 한 번에 제출하거나 끌어다 놓아도 돼요.
- 제출된 파일은 관리자 화면의 `제출물` 탭에 모이고, 저장 위치에 파일로 저장돼요.

### 🔔 실시간 알림
- `📢 공지`로 메시지를 보내면 참여자 화면에 바로 나타나요.
- 참여자의 상태 변화(화면 공유 중지, 연결 끊김, 활동 화면 이탈 등)는 오른쪽 `알림` 탭에 쌓여요.

### 🤖 AI 변화 감지
- 화면 공유 중지, 전체 화면이 아닌 창만 공유, 활동 화면 이탈 같은 **평소와 다른 변화**를 알림으로 보여줘요.
- 도우미를 설치한 기기에서는 AI 사이트 접속과 검색어도 알림으로 확인할 수 있어요.
- ⚠️ **알림은 참고 자료예요.** 브라우저가 알 수 있는 범위만 알려주며, 최종 판단은 관리자가 해요.

### ⏺ 화면 녹화
- `⏺ 녹화 시작`을 누르면 참여자 화면이 **5분 단위**로 저장돼요.
- 녹화 파일은 관리자의 **구글 드라이브 또는 PC 폴더**로 저장되고, 서버에는 남지 않아요.
- 녹화 중임을 참여자에게 미리 알려주세요.

### 🎯 집중 모드
- 활동에 맞게 환경을 정리해요.
  - **시험 모드**: 켜면 참여자가 활동 화면을 벗어났을 때 알림이 와요.
  - **🌐 인터넷 설정**: 허용할 사이트만 정해서 참여자 기기에 적용해요(도우미 필요).
  - **📝 수행평가**: 문서 · 파이썬 · 스크래치 중 도구를 골라 출제해요. 화면을 벗어나면 답안이 잠기고, 바깥 내용 붙여넣기를 막을 수 있어요. 관리자가 잠금을 풀어줄 수 있고, 학생이 쓴 과정을 다시 볼 수 있어요.
  - **📄 문서 양식**: 관리자가 만든 `.docx` 양식을 참여자가 앱 안에서 그대로 작성해요.

## 7. 지원 기기

| 기기 | 관리 방식 | 비고 |
|---|---|---|
| 💻 크롬북 · 윈도우/맥 노트북 | 브라우저(Chrome · Edge · 웨일)에서 화면 공유, **도우미 확장 프로그램** | 학교 관리 정책으로 화면 공유나 확장 프로그램이 제한될 수 있어요 |
| 📲 갤럭시탭 | **탭 도우미 앱**(화면 보기 · 사이트 제한 · 다른 앱 차단) | 앱을 직접 빌드해서 설치해야 해요 |
| 🍎 아이패드 · 아이폰 | 브라우저가 화면 공유를 지원하지 않아 **화면 확인 불가** | 파일 열기와 제출은 가능해요 |

- 화면 공유가 지원되지 않는 기기에서는 **지원되지 않는다고 표시**하고, 가짜 화면을 보여주지 않아요.

## 8. 사용 시 주의 사항

- 화면 모니터링과 녹화 사실을 **참여자에게 미리 안내**합니다.
- 개인정보와 녹화 자료를 **안전하게 관리**합니다.
- AI 알림은 **참고 자료**로 활용하며, **최종 판단은 관리자가 합니다.**

그 밖에 이런 점도 알아두세요.

- 화면 공유는 참여자가 직접 허용해야 하고, 공유 중임이 참여자 화면에 계속 표시돼요.
- 브라우저가 알 수 없는 것(다른 프로그램에서 하는 일 등)은 아는 것처럼 표시하지 않아요.
- 참여자가 도우미를 끄거나 지우면 막을 수 없어요. 대신 관리자에게 알림이 가요.
- 기관에서 쓸 때는 개인정보 처리 근거와 안내 절차, 필요한 승인을 먼저 확인하세요.

## 9. 자주 묻는 질문

**Q. 참여자도 로그인해야 하나요?**
아니요. 초대 코드와 이름만 입력하면 돼요.

**Q. "이 브라우저는 화면 공유를 지원하지 않아요"라고 떠요.**
휴대폰·태블릿 브라우저와 아이패드는 화면 공유 기능이 없어요. PC나 크롬북의 Chrome, Edge, 웨일을 사용해 주세요.

**Q. 화면 공유 창에서 무엇을 골라야 하나요?**
**전체 화면**을 선택해야 해요. 탭이나 창만 공유하면 관리자에게 알림이 가요.

**Q. 녹화 파일은 어디에 저장되나요?**
관리자의 구글 드라이브 또는 PC 폴더예요. 서버(Azure)에는 남지 않아요. 구글 드라이브 연결은 약 1시간 후 다시 연결해야 할 수 있어요.

**Q. 접속이 느려요.**
무료 플랜이라 접속이 없다가 처음 열면 몇십 초 걸려요. 서버가 다시 시작되면 진행 중이던 공간 정보는 사라져요.

**Q. 관리자 계정은 누구나 만들 수 있나요?**
구글 계정이 있으면 로그인할 수 있어요. 특정 이메일이나 학교 도메인으로 제한할 수도 있어요.
