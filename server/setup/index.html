아래 정보를 입력하면 로컬 개발 DB 준비, 작업공간·관리자 등록, 서버 설정 저장을 진행합니다. 공개 Azure 사이트에는 적용되지 않습니다.

먼저 Google Cloud에서 설정하세요

웹 애플리케이션 OAuth 클라이언트의 승인된 JavaScript 원본에 아래 주소를 모두 추가하세요.

http://127.0.0.1:5173 http://127.0.0.1:5174

Google 계정 종류와 관계없이 사용할 수 있습니다. Client secret·DB 비밀번호는 입력하지 않습니다.

관리자 이메일의 @ 뒤 부분입니다. 학교 소속을 확인하는 용도로 사용하지 않습니다.

로컬 설정이 적용되었습니다

DB 마이그레이션과 관리자 등록, 서버 환경설정 저장이 완료되었습니다. Google 계정의 실제 로그인 성공은 아직 확인하지 않았습니다.

이 설정 터미널은 DB 실행을 위해 계속 열어 두세요. API가 이미 실행 중이면 해당 터미널에서 종료 후 다시 실행하세요.

프로젝트 루트의 별도 터미널 세 개에서 각각 실행하세요.

npm run dev:server npm run dev:teacher npm run dev:student
